# 🎣 Ice Fishing Simulator - Auto-Fish Macro (AHK v1.1)

A fast, **100% undetectable** AutoHotkey macro for Roblox **Ice Fishing Simulator**. Uses pure screen pixel detection — **no executors, no DLL injection, 0% ban risk**.

### ✨ Features
- **Automatic "Perfect" Hits:** Dynamically calculates the center of the yellow target bar (works for both common and rare/tiny fish).
- **Ultra-Fast Animation Cancel:** Automatically clicks *Stop Fishing* and presses `E` right after catching a fish, skipping the 5–10s catch animation.
- **Universal Resolution Support:** Automatically scales to any monitor (`1920x1080`, `2560x1440`, `3440x1440`, etc.).

### 🚀 How to Use
1. Download and install **[AutoHotkey v1.1](https://autohotkey.com)** (make sure it's v1.1, not v2.0).
2. Download `IceFishingMacro.ahk` from this repository.
3. **Right-click** `IceFishingMacro.ahk` -> **Run as administrator**.
4. Open Roblox in **Fullscreen (`F11`)**, stand at an ice fishing hole, press **`F1`** to start the macro, and press **`E`** once to cast your rod!
